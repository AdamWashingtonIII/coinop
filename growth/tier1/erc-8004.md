# ERC-8004 (Trustless Agents) registry — assessment + registration packet

## What it is

ERC-8004 is the "Trustless Agents" standard (EIP-8004, still **Draft**): three
singleton registries per chain. The **Identity Registry** is an ERC-721 — you
mint an NFT whose `agentURI` points to a JSON registration file describing the
entity, its service endpoints (web / A2A / MCP / ENS / DID…), an
`x402Support` flag, and supported trust models. The **Reputation Registry**
lets other parties post structured feedback about the registered entity; the
**Validation Registry** (not yet deployed on any chain, per reviews) covers
independent verification. Explorers such as 8004scan index registrations for
discovery. Live on Ethereum mainnet since 2026-01-29 and deployed on Base
with the same contract addresses:

- Identity Registry (Base + mainnet): `0x8004A169FB4a3325136EB29fA0ceB6D2e539a432`
- Reputation Registry (Base + mainnet): `0x8004BAa17C55a88189AE136b182e5fdA19dE9b63`

## Does it fit a service (not an agent)?

Mostly yes, with one honest caveat. The registry's unit is an "agent"
identity, and COINOP does not act autonomously — it is a service other agents
call. But the registration file is explicitly a *service advertisement*: its
`services` array exists to publish A2A cards, MCP endpoints, and web APIs, and
the schema carries an `x402Support` boolean precisely for payable endpoints.
Payable APIs and agent-facing services do register, and the discovery
explorers present them alongside agents. Registering COINOP means: an
on-chain, wallet-owned identity that points at our agent card + discovery doc
+ MCP server, and a reputation surface where players/operators can leave
feedback that future agents can read before paying. It does **not** make
COINOP an A2A agent, and the packet copy never claims it is one.

## Recommendation

**Register — on Base, at the mainnet switch, after the agent card is live.**
Reasons: (1) cost is trivial (~$0.20 of Base gas, no protocol fee);
(2) it is the one major agent-discovery surface where *we* control the entry
and it never expires; (3) the registration file doubles as a canonical pointer
to every other surface (A2A card, discovery, MCP), so it compounds the rest of
Tier 1; (4) doing it at the mainnet switch means the file can state mainnet
terms from day one instead of being edited twice. Registering on Ethereum
mainnet too ($1–$10 gas) is optional extra reach — decide after Base.
Do **not** register before the `image` below exists (a dead image URL is the
first thing explorers show).

## The registration file (ready)

[`erc-8004-registration.json`](erc-8004-registration.json) in this folder —
complete except two placeholders to resolve first:

- `image`: points at `https://coinop-one.vercel.app/icon-512.png`, which
  **does not exist yet** (need a hosted square logo, same asset the MCP
  registries want).
- MCP service endpoint contains `<github-owner>` until the public repo exists.

Schema notes: `type`, `name`, `description`, `image` are the required fields;
service entries use `name`/`endpoint` (plus `version` where the protocol has
one). The EIP is a Draft and the file format has shifted before — re-check the
file against the EIP text at registration time (10-minute job).

**Hosting the file:** the `agentURI` must resolve publicly. Best option: serve
it from the arcade itself at `https://coinop-one.vercel.app/.well-known/agent-registration.json`
(a small follow-up route next to the agent card — not built yet, say the word).
Alternatives: IPFS via Pinata's free tier (1 GB), or a base64 `data:` URI
stored fully on-chain (more gas, zero dependencies).

## Registration steps (when the time comes)

1. Finalize + host the registration JSON (above); verify it loads over HTTPS.
2. From the owner wallet, call `register(agentURI)` on the Identity Registry
   on Base (`0x8004A169FB4a3325136EB29fA0ceB6D2e539a432`) with the hosted URL —
   one transaction, ~100–200k gas (≈$0.20 on Base). (8004.org's UI can do this
   end-to-end, including IPFS upload, if preferred over a raw contract call.)
3. Record the minted `agentId`; verify the entry on Basescan / 8004scan and
   that the registration file resolves.
4. Optionally `setAgentWallet` / update via `setAgentURI` later — the file is
   editable by re-pointing the URI; the NFT is transferable if ownership ever
   needs to move.

## Needs from the operator

| What | Why |
| --- | --- |
| Pick the owner wallet | The identity is an NFT in that wallet. Treasury wallet = simplest and matches `agentWallet` (payments); a dedicated ops wallet = cleaner separation. Either works; NFT is transferable later. |
| One signature + ~$0.25 of Base ETH in that wallet | The `register` transaction |
| The hosted logo (shared TODO with the MCP packets) | `image` must resolve |

Fee: no protocol fee — gas only (~$0.20 Base; $1–$10 if also registering on
Ethereum mainnet). Review: none — permissionless, instant on confirmation.
